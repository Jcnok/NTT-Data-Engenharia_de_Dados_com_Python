# Bootcamp NTT DATA - Analistas e Engenheiros de Dados

Repositório com as resoluções dos desafios de projeto e desafios de código do bootcamp.

<img src="img\capa.webp" align='center' alt="NTT DATA logo" width="309" height="144"/>

## Sobre:

**O Bootcamp oferece uma jornada completa desde a aprendizagem de Python até o domínio de ferramentas de tratamento de dados e dashboards com Power BI, da maneira como é feito na NTT DATA. Este é o caminho ideal para analistas e engenheiros de dados se destacarem e aumentarem suas chances de contratação nas vagas oferecidas pela empresa.**

### Oportunidades de Aprendizado:

- **Mentorias (Live)**: Inspire-se nos talentos das empresas mais inovadoras do mundo e interaja com especialistas sobre carreira e tecnologia.
- **Desafio de Código**: Teste seus conhecimentos e habilidades adquiridas nas aulas resolvendo desafios de programação.
- **Desafio de Projeto**: Construa um portfólio prático desenvolvendo projetos baseados nas competências adquiridas ao longo das aulas.
